# M2 独立复核（revision 3）

结论：建议修正后再冻结。亲自对照了原 RGB 与 checks_v3 的 0、65、85、110、130 五帧，并只读检查了 Blender 实体、合法 ViPE 几何、构建源码及导出。未访问 GT、评测、其他方法或旧模型；未修改模型，未新增渲染。当前 81 个语义对象、60 个碰撞体、180 个相机。预算仍为已用 3 轮 / 15 视图，剩余 2 轮 / 45 视图。

## 优先修项

1. **P1，桌椅仍有真实相交。** v3 只约束座椅之间。Blender 实体中 A_table 与 A_ottoman、A_ottoman_mid 的水平穿入分别为 0.124、0.386 m；B_table 与 B_chair_back、B_ottoman_left、B_ottoman_rear 分别为 0.095、0.176、0.360 m，五组均有 0.05 m 的 Z 重叠。0/65/130 帧可见桌面与座垫挤在一起。保留有较强几何证据的 A_table 中心，把桌面圆盘加入座椅间距约束，并用 RGB 调整不确定的座椅位置/半径，记录新增位移。

2. **P1，接待台法线朝向错误。** reception_desk.faceted_counter 的有符号体积为 −0.1451 m³；前面、左右侧面与背面法线朝内，底面朝上，顶部正确。当前双面显示可能掩盖问题。只需重算法线朝外并检查一致绕序，无需改尺寸、相机或尺度。

3. **P1，玻璃入口后仍有固定窗墙碰撞盒。** window_wall 是覆盖整面墙的大 AABB；入口点 (−4.45,12.04,1) 被它挡住，门内点 (−4.34,12.04,1) 另被 glass_entry_double_door 挡住。RGB 中关闭的玻璃门本身可以合理阻挡通行，但移除/打开门碰撞体后窗墙仍永久封口。应让固定窗墙避开门洞，单独保留明确的关闭门叶碰撞体；若只做静态闭门场景，应明确这一限制。若声称门可通行，还需检查门槛地板支撑。

4. **P2，镜群是最值得修的视觉地标。** 第 65 帧按 640×480 坐标，最大镜 mirror_00 的模型中心为 (500.6,166.8)，原 RGB 对应大镜约为 (365,193)，约向右偏 136 px、向上偏 26 px。第 0 帧原图右缘有明显圆镜，模型却未呈现该镜群；第 85 帧模型镜群也难以辨识。建议用 65/85 帧重新确定墙面上的 y/z 位置与半径，以第 0 帧交叉确认，保留相机和刚体 T。

5. **P3，导出相机仅有极小 fy 误差。** 输入 fy=765.67218，GLB 实际约为 765.53290，相差 −0.13928 px（0.0182%）；保存 blend 的 pixel aspect 还是 1:1，而检查渲染循环才设置 fx/fy。图像边缘影响低于 0.1 px。可在保存/导出前设置一致的纵横比，或明确 glTF 投影的这项近似；优先级低于上面几项。

## 已通过的约定与几何证据

- 变换方向经数值确认：列向量 p_model = T_input_model @ p_input，且 c2w_model = T_input_model @ c2w_input。旋转奇异值均为 1，det=1.0000000000000002；180 个相机组合误差最大 1.78e−15，导出的 c2w_input 与 packet pose 完全一致。
- Blender 相机正确使用 c2w_model @ diag(1,−1,−1,1)，最大误差 3.43e−7；GLB 使用 (x,y,z)_glTF=(x,z,−y)_model，最大位姿误差 4.72e−7。未见相机方向反转或整体尺度拟合。
- 原生 ViPE 尺度保留声明可信：构建/推导代码只使用刚体变换和给定 pose 的 RGB 三角化。近桌中心的两帧原生深度回投约为 (−0.567,5.293,0.530)、(−0.569,5.261,0.514)，与手工三角化 (−0.561,5.247,0.533) 相符。
- 远墙冲突确实存在：盾牌尖端在第 0 帧原生深度给出 y≈11.722，第 130 帧给出 y≈14.988，而 RGB 双视图给出 y≈15.560；复算重投影误差仅 0.613/0.775 px。采用后者并记录冲突有依据。这不等于证明绝对真实米制尺度正确。
- 地板碰撞体由两个真实板块组成，保留 L 形，rug 的 role=floor 正确；四个木墙开口的中心样点均未被 obstacle 碰撞体封住。玻璃入口问题另见 R3。
- 五个 v3 视图中未见先前明显的座椅间黑色新月，座垫顶盖平面法线处理可接受；但不能据此宣称全部家具无相交。
- 362 条输入访问日志均在合同/packet/RGB/geometry 许可集合中；检查过的派生源码没有外部几何或尺度拟合读入。81 个命名语义组由参数化几何构建，点云仅作测量证据。

## 可保留的残差与预算建议

植被比 RGB 更密、更高，尤其 85/130 帧遮挡了更多座椅；黑色地面呈明显条纹，与原图细织纹及点状反射不同；0/65 帧前景座椅仍显粗大，可随桌椅约束修正一起改善。模型多个视角有较强的墙脚黑条，其原因本次未单独隔离。若干旋转体花盆/碗存在开放边界，但现有视图没有相应黑洞，隐蔽厚度已标为推断。

建议下一轮集中修复相交、法线及入口碰撞语义，尽可能同时修镜群，然后重新看同五个合法输入视图。最后一轮留给新检查揭示的残差；不要用整体尺度或相机变换去吸收反射深度冲突。
