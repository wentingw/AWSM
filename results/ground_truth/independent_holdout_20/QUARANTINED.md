# Diagnostic artifacts, excluded from final appearance/depth truth

The RGB files in this directory are Workbench gray-clay renders, not original Isaac RTX appearance GT. The compositor-derived `*_zdepth.npy` arrays failed independent exact GT-BVH numerical validation (systematic approximately 0.7–0.9 m MAE). Neither is used in final novel-view metrics.

The deterministic camera pose manifest remains usable. The authoritative replacement is `results/evaluation/novel_depth/report.json` and `gt_samples.npz`, generated by `scripts/evaluate_novel_depth_blender.py` directly from the metric GT mesh. It verifies 9,984,967 triangles, stores the actual sampled rays, and uses the same GT-only depth domain for every prediction. No new-view RGB score is published.
